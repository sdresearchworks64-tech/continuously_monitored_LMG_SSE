# continuously_monitored_LMG_SSE
Inspired from Santini et al 's work PhysRevB.111.134305
Idea of the paper is that : connect a collective spin system with a qubit which essentially acts as a detector, provided that the interaction between them is weak. The system + bath evolution is unitary , so one can use Schrodinger equation to see the evolution. But the catch is that, we only want to observe how the dynamics of the system is influenced due to the coupling. So we can do some simplification of the evolution and only find the state of the system conditioned with the outcome of the detector. This business is done using the initial correlation to be zero, random outcomes of the detector that helps to build the stochastic schrodinger equation for the system of interest.
The outcome is that for a particular value of dissipation rate , one can see phase transition (which people call measurement induced phase transition). Here phase transition to be clear is simply quantified by average z magnetization goes to -M to +M.
